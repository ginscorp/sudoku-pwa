# Presentation assets / Материалы оформления

The four screenshots show the actual standalone public Sudoku 0.1.0 UI, captured on 2026-11-02 in Chrome mobile emulation using synthetic game data and an isolated profile. The UI is Russian. The covers arrange these same screenshots with HTML/CSS. The rounded frames are presentation graphics, not photos or proof of a physical-device test. No account, private game history, working service URL or browser profile is part of these assets.

Четыре скриншота показывают настоящий интерфейс самостоятельной публичной версии0.1.0: мобильная эмуляция Chrome, вымышленные партии и отдельный профиль. Обложки оформлены из этих же кадров средствами HTML/CSS. Рамки не являются фотографиями устройства и не подтверждают проверку физического телефона. Аккаунты, личные партии, рабочие адреса и профили в материалы не входят.

- game-dark.png — dark game with pencil marks / темная игра с заметками.
- game-paper.png — paper theme / бумажная тема.
- lesson-xwing.png — a guided X-Wing lesson / учебный разбор X-Wing.
- replay.png — local move replay with synthetic data / локальный разбор тестовой партии.
- hero-en.png, hero-ru.png — localized covers / локализованные обложки.
