# Sudoku PWA

[English](README.md) · [Русский](README.ru.md)

Самостоятельная игра в судоку с офлайн-режимом, обучением и локальным журналом ходов. Публичная версия **0.1.0**. Интерфейс сейчас **на русском**; документация доступна на английском и русском.

## Возможности

- Семь уровней сложности и 2200 сгенерированных задач; тесты независимо проверяют единственность решения каждой задачи каталога.
- Карандаш, кандидаты, подсказки, отмена/возврат, пауза, учет активного времени, темы и статистика. Ошибки не завершают игру.
- 39 уроков со схемами, вопросами и практическими позициями.
- Локальное автосохранение, пошаговый разбор и выгрузка JSON-журнала партии по действию пользователя.
- Service worker подготавливает приложение для офлайн-работы после первой успешной загрузки.

Публичная версия выделена из существующего приложения. Для самостоятельного запуска удалена интеграция аккаунта/сервера, отделены имена локальных хранилищ и добавлен просмотр только статических файлов. Сервиса аккаунтов и облачной синхронизации в этой версии нет.

## Локальный запуск

Требуются Python 3.10+ для сервера просмотра и современный браузер с JavaScript, localStorage, IndexedDB и service worker. Node.js 20+ нужен только для тестов. Зависимостей npm и этапа сборки нет.

1. Скачайте ZIP репозитория и распакуйте его.
2. Откройте терминал в распакованной папке и выполните:

```sh
python3 scripts/serve.py
```

3. Откройте <http://127.0.0.1:8767/>. Перед проверкой перезагрузки без сети дождитесь **Офлайн готово**. Остановка сервера — Ctrl+C.

Другой порт: `python3 scripts/serve.py --port 8768`; в браузере откройте соответствующий порт. Сервер доступен только через loopback и отдает только `dist/`. Открытие `index.html` как файла не создает поддерживаемую среду модулей и офлайн-режима.

Для другого устройства разместите содержимое `dist/` на собственном статическом HTTPS-хостинге. Телефон не обращается к компьютеру через свой loopback-адрес. Репозиторий не настраивает хостинг и не включает GitHub Pages автоматически. Установку на домашний экран и работу физического устройства проверяют отдельно на выбранном устройстве.

## Как проверяются дополнительные задачи

2200 задач — проверенный базовый каталог. Первые четыре уровня сначала пробуют новую генерацию: строится полное решение, затем цифры удаляются только пока ограниченный перебор подтверждает ровно одно решение. Второе решение или исчерпанный лимит поиска отменяют удаление. Более сложные уровни используют сохраняющие судоку преобразования каталога: перенумерацию цифр, допустимые перестановки групп строк/столбцов и транспонирование, затем повторно проверяют единственность и полученный уровень. Резервный вариант — проверенная исходная задача каталога. Преобразования дают варианты существующих структур, а не обещание бесконечного числа принципиально новых структур.

Независимый тестовый решатель проверяет весь базовый каталог и выборочные сгенерированные/преобразованные случаи. Во время игры используется игровой решатель. Единственный ответ отличается от полного понятного логического разбора: набор поддержанных подсказок может закончиться, а явное раскрытие клетки обозначается как ответ из решения. Формальные сертификаты доказательства не сохраняются.

## Проверки

```sh
node --test tests/*.test.mjs
```

Тесты проверяют каталог, решатель, переходы состояния, подсказки, схемы кандидатов, статистику, генерацию worker, ввод закрытой цифры и офлайн-кеш. Браузерные проверки и фактически использованные среды выпуска записаны в [VALIDATION.md](VALIDATION.md). Результат настольного браузера или мобильной эмуляции не подтверждает работу физического iPhone или всех браузеров.

## Файлы и технологии

В `dist/` находятся поддерживаемые исходники HTML, CSS и браузерного JavaScript, включая движок и сгенерированный каталог в `dist/js/`. Эту папку нельзя отбрасывать как временный результат сборки. `dist/sw.js` отвечает за офлайн-кеш. `scripts/serve.py` использует стандартную библиотеку Python, `tests/` — встроенный тестовый запускатель Node.js.

## Данные и сеть

Партии, настройки, прогресс обучения и случайно создаваемые локальные идентификаторы остаются в localStorage/IndexedDB этого браузера. Очистка данных браузера или смена origin/порта может сделать сохранения недоступными. Выгружайте нужные журналы: удаленного бекапа и восстановления между устройствами в этой версии нет. Для демонстрации используйте новый профиль браузера. Личные партии и профили в комплект не входят.

Обычная игра загружает собственные статические файлы приложения без запросов аккаунта/API/аналитики. Необязательные учебные ссылки открывают сторонние сайты только по выбору пользователя. Сервер просмотра выводит пути запросов в свой терминал. Вход, API-ключ, повышенные системные права и специальные разрешения устройства не требуются.
